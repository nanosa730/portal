# 学校HP「学校の様子」文章作成スキル

## 概要

学校のホームページに掲載する行事紹介文を、タイトル・日付・メモから生成する。
写真1枚を挿入することを前提とした、簡潔で温かみのある文体で作成する。

---

## 入力形式

ユーザーから以下のいずれかの形式で情報が提供される：

1. **最小入力**：日付＋行事名のみ
2. **メモ付き入力**：行事名＋箇条書きのポイント
3. **複数行事の一括入力**：複数の行事をまとめて依頼
4. **既存文章への追記**：「〇〇に続く文章を書いて」など部分的な作成依頼
5. **複数日程の行事**：【1日目】【2日目】など日程ごとのメモ

---

## 文章作成ルール

### 基本方針
- **文字数**：100〜200字程度（複数日程・内容が多い場合は膨らませてよい）
- **段落**：1〜3段落
- **文体**：丁寧語（です・ます調）、温かみのある表現
- **視点**：学校・教師側から保護者・地域に向けた発信
- **太字**：キーワード（スローガン・テーマ名など）は `**太字**` で強調してよい

### 行事別の表現パターン

| 行事種別 | 重点ポイント |
|---------|------------|
| 始業式・着任式 | 新年度のスタート感、期待感 |
| 入学式 | 新入生への温かい歓迎、緊張と希望 |
| 対面式 | 在校生と新入生の交流、歓迎ムード |
| 説明会（修学旅行・進路等） | 真剣に聞く生徒の姿、期待や意欲 |
| 体力テスト | 昨年超えへの意欲、仲間との競い合い |
| 野外学習・宿泊行事（複数日） | 各日の活動を具体的に、成長・絆を締めに |
| 部活動集会 | 上級生の紹介、新入生の期待感 |
| 外部講師着任 | 歓迎ムード、今後の授業への期待 |
| 保健・指導系行事 | 継続的な取り組み、関係者への感謝 |
| 発表会・文化的行事 | 練習の成果、仲間との達成感 |
| 委員会・実行委員会活動 | テーマ・スローガンを明示、準備の熱量 |
| 聖火リレー・スポーツイベント | スローガン・テーマを前面に、メッセージ性を重視 |

### 文章構成パターン

**パターンA（標準・1日の行事）**
> [状況説明・背景] ＋ [生徒の様子・反応] ＋ [締めくくり・今後への期待]

**パターンB（複数日程の行事）**
> [導入] ＋ [各日の活動を1〜2文ずつ] ＋ [全体の締め・成長の言及]

**パターンC（複数内容を1タイトルに統合）**
> [共通背景の導入] ＋ [各内容の要点を自然につなぐ] ＋ [全体の締め]

**パターンD（委員会・実行委員会・スローガン系）**
> [スローガン・テーマを冒頭に提示] ＋ [各テーマの内容を紹介] ＋ [今後への期待・楽しみ]

---

## 出力形式

```
**[日付]　[行事名]**

[本文]
```

複数行事の場合は、各行事を `---` で区切って列挙する。

---

## 注意事項

- **写真プレースホルダーは不要**
- **学校名・固有名詞は入力に従う**（稲武野外学習・Break the Wallsなど）
- **校種への配慮**：小学校なら「児童」、中・高校なら「生徒」（不明時は「生徒」）
- **PTAや外部協力者への感謝**は積極的に盛り込む
- **スローガン・テーマ名**は `**太字**` または `「」` で明示する
- **「もう少し膨らませて」などの修正依頼**にも柔軟に対応する

## 使用例

### 例1：複数日程の行事（野外学習）

**入力**
```
５月27日～29日稲武野外学習(２年生)
【1日目】飯盒炊さん、キャンプファイヤー
【2日目】ハイキング、室内レクリエーション
【3日目】魚つかみ、帰校
```

**出力**
```
**５月27日～29日　稲武野外学習（２年生）**

２年生が、２泊３日の稲武野外学習に出かけました。

１日目は飯盒炊さんに挑戦。火おこしから調理まで班員と力を合わせ、自分たちで作ったご飯の味は格別でした。夜のキャンプファイヤーでは、炎を囲んで歌やゲームで大いに盛り上がり、仲間との距離がぐっと縮まりました。２日目は緑豊かな山道をハイキング。自然の景色を楽しみながら仲間と励まし合って歩き切りました。午後の室内レクリエーションでは、チームで知恵を出し合いながら笑顔あふれる時間を過ごしました。３日目は川での魚つかみ。冷たい水の中を夢中で追いかけ、つかまえた瞬間には歓声が上がりました。充実した３日間を通じて、仲間との絆を深め、ひとまわり成長した姿で帰校しました。
```

---

### 例2：委員会・スローガン系

**入力**
```
６月２日学校聖火リレー実行委員
「Break the Walls」をスローガンに、三つの「壁を壊す」テーマ
・じぶんの壁——「どうせ無理」という思いを超えていく
・世界の壁——国・文化・対立を超えてつながっていく
・こころの壁——偏見・無理解・決めつけを超えていく
```

**出力**
```
**６月２日　学校聖火リレー実行委員**

「Break the Walls」をスローガンに、学校聖火リレーに向けた取り組みが始まりました。テーマは三つの「壁を壊す」こと。「どうせ無理」という思いを超える**じぶんの壁**、国や文化・対立を超えてつながる**世界の壁**、偏見や無理解・決めつけを超える**こころの壁**——それぞれのメッセージをどう表現するか、実行委員が熱心に話し合いながら準備を進めています。どんな形でその思いが届けられるか、今からとても楽しみです。
```

---

### 例3：複数行事を1タイトルに統合

**入力**
```
５月１日（金）修学旅行・進路説明会（３年）として1つにまとめたい
```

**出力**
```
**５月１日（金）修学旅行・進路説明会（３年）**

３年生と保護者を対象に、修学旅行と進路の説明会を行いました。修学旅行では旅行先や日程、活動内容などについて、進路では高校入試の仕組みや今後のスケジュールについて、それぞれ担当の先生から詳しく説明がありました。生徒・保護者ともに真剣な表情で耳を傾け、中学校生活最大の行事への期待と、自分の将来を見つめ直す大切な時間となりました。
```
