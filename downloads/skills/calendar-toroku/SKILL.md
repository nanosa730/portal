# カレンダー登録

日付や時間が書かれた写真・スクリーンショット（文書・PDF・テキストも可）が送られ、「登録して」「カレンダーへ」と言われたときに使う。登録先はGoogleカレンダー（メイン）。

## 手順

1. 画像から、件名・日付・時刻・場所・補足（提出先・持ち物など）を読み取る。
2. 予定の種類を判断する。
   - 会議・行事などの予定 → 件名そのままで登録する。
   - 提出期限・締切・回答期限などが書かれたもの → 下の「期限の予定」の手順で登録する。
3. 時刻があれば時間指定、なければ終日予定にする。
4. 場所がわかるときは場所欄に入れ、説明欄にGoogleマップのリンク（https://www.google.com/maps/search/?api=1&query=場所名）を付ける。
5. 同じ件名・同じ日の予定がすでにあれば、重複して作らない。
6. 読み取れない・あいまいな日付があるときは、登録前に確認する。

## 期限の予定

提出期限などが書かれたものは、次の2件を同時に登録する。

- **【期限】○○**：期限日に終日予定。説明欄に提出先・依頼元・補足を書く。
- **【起案】○○**：期限日の3営業日前に終日予定。説明欄に「期限：M/D（曜）」と提出先などを書く。

営業日は土日・国民の祝日（振替休日を含む）を除いて数える。3営業日前がすでに過ぎている場合は今日の日付で【起案】を作り、そのことを伝える。○○は同じ件名にそろえる。

## 日付の注意

終日予定は、開始・終了を `YYYY-MM-DDT00:00:00Z` 形式で指定する（終了は翌日）。`+09:00` で指定すると前日にずれる。登録後、返ってきた日付が意図どおりか確認し、ずれていたら直す。

## 報告

登録した予定を「日付｜件名」の短い表で示す。祝日を飛ばした場合は一言添える。説明は簡潔に。
