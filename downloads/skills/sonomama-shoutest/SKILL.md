# そのまま小テスト

問題集の問題を、そのままGoogleフォームの小テストにする。教師用（赤刷り）の問題集を
前提とし、赤字の答えをそのまま正解として使う。

生徒にとっては「やった問題がそのまま出る」ので、問題集に取り組んだかどうかが点数に出る。
これがこの小テストの目的であり、ひねった問題を作らない理由でもある。

## 全体の流れ

1. PDFを読む
2. 重要語句を問う5問を選ぶ（＋差し替え候補）
3. チャットに表で提示して確認を取る
4. OKが出たらTSVを書き出して渡す

TSVを先に作ってはいけない。誤読が混ざったまま生徒に届くのを防ぐため、必ず3の確認を挟む。

## Step 1: PDFを読む

```bash
python3 scripts/pdf_pages.py 問題集.pdf --out /tmp/pages
```

ページごとにPNGと、テキスト層があれば.txtが出る。テキスト層があるならそれを読むのが速い。
ないときは Read ツールでPNGを見る。

読むときの手がかり:

- **赤字・色文字が答え**。教師用の問題集は答えが刷り込まれている
- **★や太字の「重要用語」欄**があれば、それが出題すべき語句そのもの。最優先で使う
- 問題番号と解答欄の対応がずれやすいので、答えの数と問題の数が合うか確かめる

## Step 2: 5問を選ぶ

毎回5問、1問1点の5点満点。選ぶ順は次のとおり。

1. **重要語句**（★印・太字・巻末の用語一覧にあるもの）
2. 定期テストで頻出の用語
3. 単元の中心概念

計算だけの問題、作図の問題は選ばない。小テストとして扱いにくく、語句の定着確認という
目的からも外れる。

**図つき問題も時々入れる**（5問中1問まで）。「図の器具の名称」「この動物の名前」程度のもの。
毎回入れる必要はない。

選ばなかった問題は捨てずに**差し替え候補**として残す。先生が「4番を候補Aに」と言えるように
しておくと、やり取りが一往復で済む。

### 問題文の直し方

問題文は問題集のまま使う。ただしフォームは前の問題を参照できないので、そこだけ補う。

- 「(4)以外の物質を何といいますか」→「**有機物**以外の物質を何といいますか」
- 穴埋めの①②を両方問う形 → ②だけを問う形に分ける

**補った箇所は提示のときに必ず伝える。** 先生が原文と見比べられるようにするため。

## Step 3: 形式を決める

| 形式 | 使うとき |
|---|---|
| 記述 | 漢字表記が一意に決まる用語（密度・節足動物・有機物）、英単語、単位つきの数値 |
| 選択 | 送り仮名が割れる語、ひらがなと漢字が揺れる語、カタカナ人名、長い説明、化学式 |
| 複数選択 | 正解が2つ以上ある問題 |

迷ったら記述にして、許容解を厚めに登録する。書いて答えるほうが記憶に残るため。
表記ゆれは許容解で吸収できるので、恐れなくてよい。

- 図を見て名前を答える問題は記述にし、**カタカナとひらがなの両方**を許容解に入れる
- 問題集にもともと選択肢があるなら、その選択肢をそのまま使う
- 選択肢のない一問一答を選択式にするときは、**同じ範囲の他の問題の答え**をダミーにする（4択）。
  範囲外の語を混ぜると、消去法で解けてしまう

## Step 4: チャットに提示する

この形で出す。

```
## 理科 そのまま小テスト p.50-51（5点満点）

| # | 問題 | 形式 | 正解 | 許容解 |
|---|---|---|---|---|
| 1 | 食器は、使う目的や形などで…これを何といいますか。 | 記述 | 物体 | ぶったい |
...

## 差し替え候補

| 候補 | 問題 | 形式 | 正解 |
|---|---|---|---|
| A | 有機物以外の物質を何といいますか。 | 記述 | 無機物 |
...

**原文から変えた箇所**: 問4は「(4)以外の」→「有機物以外の」と補いました
```

図を入れた問題があれば、切り出した画像も送って見てもらう。図がずれて切れていることが
あるので、TSVにする前に一度見せる。

## Step 5: TSVを書き出す

確定したらJSONに起こして、スクリプトに通す。

```bash
python3 scripts/make_tsv.py 問題.json -o 2026-09-15_理科_p50-51.tsv
```

JSONの形:

```json
{
  "round_id": "2026-09-15-理科1年",
  "subject": "理科",
  "range": "p.50-51",
  "questions": [
    {"number": "1", "type": "記述", "text": "…", "answer": "物体", "accepted": ["ぶったい"]},
    {"number": "4", "type": "記述", "text": "図のAのねじの名称を書きなさい。",
     "answer": "空気調節ねじ", "accepted": ["くうきちょうせつねじ"], "image": "/tmp/fig.png"},
    {"number": "候補A", "type": "記述", "text": "…", "answer": "無機物", "enabled": false},
    {"number": "候補E", "type": "選択", "text": "…",
     "choices": ["展性", "延性", "光沢", "磁性"], "answer": "展性", "enabled": false}
  ]
}
```

`enabled: false` が差し替え候補。シートの「出題」列に `false` が入るので、先生はその文字を
消すだけで入れ替えられる。

スクリプトは列順・区切り文字・図の埋め込み・正解と選択肢の整合まで面倒を見る。
手でTSVを組み立てると列がずれたり正解が選択肢に無かったりするので、必ずこれを通す。
エラーが出たらJSONを直して再実行する。

**回ID** は `日付-教科学年`（例 `2026-09-15-理科1年`）。同じ回IDの行がまとめて1つのフォームになる。

最後にTSVファイルを先生に渡し、「問題銀行シートのA1に貼り付け → メニューから小テストを作成」
と案内する。

## 図つき問題の作り方

図はDriveに置かせない。画像データをTSVのセルに埋め込むので、先生の作業はゼロになる。

```bash
# まずページ全体を見て、切り出す場所の見当をつける
python3 scripts/crop_figure.py 問題集.pdf /tmp/page.png --preview
# 座標を指定して切り出す（left,top,right,bottom）
python3 scripts/crop_figure.py 問題集.pdf /tmp/fig.png --box 140,588,342,782
```

切り出したら必ず自分で見る。枠線や隣の文字が写り込んでいたら座標を調整する。
あとは JSON の `image` にパスを書けば、make_tsv.py が埋め込む。

図の中に答えが書かれていないかも確認する。赤刷りの問題集では、図の中に答えが
入っていることがある。

## 前提にしている運用

このスキルが作るTSVは、Googleスプレッドシート側の「そのまま小テスト」スクリプトが読む。
先生の手順は、TSVを貼る → メニューを押す → できたフォームを学校アカウントでコピーして
Classroomに配る、の3手順。

- 記述式の自動採点は Google Forms API を使うので、フォーム生成側で設定が要る
- 問題の並びはシャッフルしない（問題集と同じ順にして、間違い直しをしやすくするため）
