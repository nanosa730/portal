# 決裁文書チェック（kessai-check）

学校から出す文書を決裁する立場の教員向け。利用者は**紙に手書きで修正を入れる**ので、指摘は「原稿のどこか」が一目でわかることが最優先。時間をかけてよいので品質を優先する。

## 成果物

1つのPDF（`/mnt/user-data/outputs/<文書名>_校正チェック.pdf`）を作って `present_files` で渡す。
- 前半：原稿各ページに番号付きの枠を描いた画像（赤＝要修正、青＝推奨）
- 後半：修正一覧表（No／区分／場所／現在／修正案／理由・備考）と、確認済み事項

チャットの返答は簡潔に：要修正（赤）だけを番号付きで「現在→修正案（理由）」の形で列挙し、推奨（青）は種類をまとめて一言、最後に確認済み事項（曜日など）を一行。

## 手順

### 1. 原稿を読む
- 添付の内容がコンテキストに見えていても、座標取りのために画像化する：
  `python3 scripts/render_pages.py <入力ファイル> <作業dir>` → `p-1.png …`（150dpi）と、座標グリッド付き `g-1.png …` を作る。Word（.docx）は先に `soffice --headless --convert-to pdf` でPDF化。写真（jpg/png）はそのまま使える。
- 全文を一字ずつ読む。イラスト内の文字、見出し、キャプション、囲み、保護者欄まで漏らさない。

### 2. 指摘を洗い出す
`references/checklist.md` の観点で全項目を点検する。特に見落としやすいのは次のとおり。
- 主語と述語のねじれ、並列（〜たり〜たり）の崩れ、接続詞（つまり・だから）の論理
- **誤読のおそれ**（例：実験の結果を「生徒が実際に感染した」と読める書き方）
- **保護者宛ての敬語**（「人」→「方/生徒」、「結構です」「〜してしまった」「させていただく」の多用、「もらった」などくだけた語）
- **手順の論理**（受診前に提出と読める、など）
- **安全面**（やけど・けが・受診が必要な症状への一言）
- 数値・日付・曜日の確認（曜日は計算して確かめる）、数値の根拠（公的ガイドラインとの食い違い）、同じ数字が別の意味で使われていないか
- 表記揺れ（ひと/人、ちがう/違う、生まれる/産まれる、あわせる/合わせる など）、重複表現、余分な空白・読点
- 人名・所属・肩書は原稿だけでは確定できないので「依頼文書等で要確認」と書く（推測で直さない）
- 生徒の感想（引用）は原文尊重。明らかな誤り（不要な読点など）だけ指摘し、言い回しは「原文どおりなら可」と添える

区分は2つだけ：**要修正（赤）**＝誤り・誤解のおそれ・不適切な敬語・安全面／**推奨（青）**＝表記揺れ・より良い表現・検討事項。

修正案は**手書きで直しやすい最小の書き換え**を優先する。大きく書き換える必要があるときは完成文を示す。

### 3. 座標を取る（いちばん失敗しやすい工程）
- 表示される画像は縮小されているので、**見た目の位置から座標を推定しない**。必ず等倍の切り出しにものさしを付けて読む：
  `python3 scripts/ruler_crop.py <作業dir>/p-1.png x0 y0 x1 y1 <出力.png>`
  （幅1240以下の範囲を切り出すと縮小されずに表示されるので、目盛りから実座標を読める）
- 枠は指摘する語句だけを囲む（少し余白をとる）。複数行にまたがる語句は行ごとに矩形を分ける。
- 描画後は必ず該当部分を切り出して目視で確認し、ずれていたら直す。2〜3回の調整は普通。

### 4. items.json を書く
形式は `references/items_format.md`。番号ラベルの置き方：
- 基本は余白（左か右）に置き、細い引き出し線で枠につなぐ。**引き出し線が本文の文字の上を横切らない**ように、枠の高さの中央で余白から枠へ直接つなぐ（`"side":"L"` / `"side":"R"`）。
- 同じ行に複数の指摘があって引き出し線が他の枠を横切る場合や、イラストの吹き出しなどは、枠の角に直接置く（`"at":[cx,cy]`）。
- 同じ行の関連する指摘（例：保護者欄の同じ行の「人」と「させていただき」）は1つの番号にまとめてよい。

### 5. 描画とPDF化
```
python3 scripts/annotate.py items.json <作業dir>        # → a-1.png …
python3 scripts/make_report.py items.json <作業dir> "<出力PDFパス>" "<タイトル>"
```
`make_report.py` はIPAゴシックを埋め込む（埋め込みなしのCIDフォントは表示されない環境があるため使わない）。「場所」欄は「表面・前文4行目」「裏面・保護者欄2行目」のように、紙の上で探せる書き方にする。

### 6. 渡す
`present_files` でPDFを渡し、上の「成果物」のとおり簡潔に返答する。印刷配布物の注意（灰色文字・網掛けは学校のプリンターで見えにくい）に関わる箇所があれば推奨として指摘する。
