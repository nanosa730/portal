# items.json の形式

```json
{
  "pages": {"1": "p-1.png", "2": "p-2.png"},
  "side_names": {"1": "表面", "2": "裏面"},
  "notes": "確認済み：9月4日は金曜日で正しい。",
  "items": [
    {"no": 1, "level": "blue", "page": 1,
     "place": "前文4行目", "current": "喉の乾燥や喉の痛み",
     "fix": "喉の乾燥や痛み", "reason": "「喉の」の重複",
     "rects": [[282,388,492,425]],
     "labels": [{"side": "L"}]},
    {"no": 18, "level": "blue", "page": 2, "place": "イラスト左の吹き出し",
     "current": "…", "fix": "…", "reason": "…",
     "rects": [[570,400,873,485]],
     "labels": [{"at": [552,392]}]}
  ]
}
```

- `level`: `red`（要修正）／`blue`（推奨）
- `rects`: 実ピクセル座標（150dpi画像）[x0,y0,x1,y1]。複数行は行ごとに。
- `labels`: 省略すると最初の矩形に対し、左半分なら左余白・右半分なら右余白に自動配置。
  - `{"side":"L"|"R"}` … 余白に置き、対象矩形（`"rect":i` で指定、既定0）の縦中央へ引き出し線
  - `{"side":"L","y":1483}` … 引き出し線の高さを指定（行間を通したいとき。線は枠の辺まで縦に伸ばす）
  - `{"at":[cx,cy]}` … 指定位置に直接置く（線なし）
- 一覧表の「場所」は `side_names` の名前を頭に付けて表示する（例：「表面・前文4行目」）。
