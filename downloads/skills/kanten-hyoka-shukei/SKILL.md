## 使う場面
- テスト結果の詳細CSV（例：「詳細_〇〇市立〇〇中学校_R8年度1年2学期中間テスト_…csv」）をExcelで開き、観点ごとのA・B・Cの人数を見ながらカットラインを決めたいとき。
- 「観点別にABCの人数を出して」「カットラインを決めたい」「前回と同じ分析をして」などと言われたとき。

## 前提（データの形）
- 1行目が見出し、2行目から生徒1人1行。
- 必要な列（見出しの文字で探す。列の位置は決め打ちにしない）
  - 「組」…学級（A〜Fなど）
  - 「観点配点 | 知識・技能」「観点得点 | 知識・技能」
  - 「観点配点 | 思考・判断・表現」「観点得点 | 思考・判断・表現」
- 欠席者は観点得点が空欄。空欄の生徒は数えない。
- 観点が3つ（「主体的に学習に取り組む態度」など）ある場合は、同じ形で行を1つ増やす。組み合わせの表は2観点のときだけ作り、3観点ならどうするかユーザーに確認する。

## 手順

### 1. データの確認
execute_office_js で見出し行（1行目）と使用範囲を読み、次を把握する。
- 上の5列の列記号と、最後のデータ行（例：190）
- 使用範囲の右端の列。表は右端から2列あけた列（例：右端がLGならLJ）から置く。以下ではその列を「LJ」として説明する。
- 学級の一覧（「組」の列の重複をなくしたもの）
- 置く場所が空いているか。空いていなければユーザーに確認する。

Done when：列記号、最後の行、学級の一覧、置き場所の列が決まっている。

### 2. カットライン表（LJ2:LV6）
- LJ2：「評価人数（黄色のセルにカットラインの点数を入力）」（太字）
- 4行目の見出し：観点｜配点｜A：何点以上｜Aの得点率｜C：何点以下｜Cの得点率｜A人数｜B人数｜C人数｜受験者数｜A割合｜B割合｜C割合（LJ〜LV）
- 5行目：知識・技能、6行目：思考・判断・表現
- 数式（知識・技能の例。得点列をM、配点列をL、最後の行を190とした場合。思考・判断・表現は得点列・配点列を差し替える）
  - 配点：`=MAX($L$2:$L$190)`
  - A：何点以上／C：何点以下：**入力セル**。最初は配点の80%を切り上げた点数と、50%を切り捨てた点数を数値で入れる。黄色地・青字・太字にする。
  - Aの得点率：`=LL5/LK5`、Cの得点率：`=LN5/LK5`（0.0%）
  - A人数：`=COUNTIFS($M$2:$M$190,">="&LL5)`
  - C人数：`=COUNTIFS($M$2:$M$190,"<="&LN5)`
  - 受験者数：`=COUNT($M$2:$M$190)`
  - B人数：`=LS5-LP5-LR5`
  - 割合：`=LP5/$LS5` など（0.0%）

Done when：5・6行目にエラーがなく、A＋B＋Cが受験者数と同じになっている。

### 3. 評価の組み合わせ表（LJ9:LL17）
- LJ9：「2観点の評価の組み合わせ（順不同）」
- 10行目の見出し：組み合わせ｜人数｜割合
- 11〜16行目：AA, AB, AC, BB, BC, CC（BCも必ず入れる。入れないと合計が受験者数にならない）。17行目：合計
- 人数は次の LET の数式に、最後の部分だけ組み合わせごとに差し替えて入れる。
  `=LET(k,$M$2:$M$190,t,$O$2:$O$190,ok,ISNUMBER(k)*ISNUMBER(t),kA,(k>=$LL$5)*ok,kC,(k<=$LN$5)*ok,kB,ok-kA-kC,tA,(t>=$LL$6)*ok,tC,(t<=$LN$6)*ok,tB,ok-tA-tC, …)`
  - 最後の部分：AA＝`SUM(kA*tA)`、AB＝`SUM(kA*tB+kB*tA)`、AC＝`SUM(kA*tC+kC*tA)`、BB＝`SUM(kB*tB)`、BC＝`SUM(kB*tC+kC*tB)`、CC＝`SUM(kC*tC)`
- 割合：`=LK11/$LK$17`（0.0%）。合計：SUM。
- 数式が #NAME? になる（LETが使えない）ときは、SUMPRODUCT で同じ条件を書き直す。

Done when：合計が受験者数と同じになっている。

### 4. 学級別の表（LJ20〜）
- LJ20：「学級別　観点別評価の人数と割合」
- 21行目：学級（21・22行目を結合）｜「知識・技能」（LK:LQを結合）｜「思考・判断・表現」（LR:LXを結合）
- 22行目：A人数｜A割合｜B人数｜B割合｜C人数｜C割合｜受験者数（両方の観点で同じ並び）
- 23行目から学級を1行ずつ並べ、最後に「学年全体」の行を付ける。
- 数式（学級の組の列をD、学級名のセルを$LJ23とした場合）
  - A人数：`=COUNTIFS($D$2:$D$190,$LJ23,$M$2:$M$190,">="&$LL$5)`
  - C人数：`=COUNTIFS($D$2:$D$190,$LJ23,$M$2:$M$190,"<="&$LN$5)`
  - 受験者数：`=COUNTIFS($D$2:$D$190,$LJ23,$M$2:$M$190,">=0")`
  - B人数：受験者数－A－C
  - 割合：`=IFERROR(人数/受験者数,0)`（0.0%）
  - 学年全体：人数と受験者数はSUM、割合は合計どうしで割る。

Done when：学年全体の行が、カットライン表の人数と一致している。

### 5. 書式と確認
- 見出しは薄い青（#D9E1F2）の塗りつぶしで太字。表には罫線を引き、中央揃えにする。合計の行は太字にし、上を二重線にする。
- 列の幅はLJが110、ほかは70くらい。**行の高さは変えない**（行全体に効くので、生徒データの行も変わってしまう）。
- 最後に範囲を画像にして見た目を確かめ、数式のエラーがないことと合計が合うことを確認する。

## 報告
- 3つの表の場所と、カットライン表・学級別の表の主な数値を短く伝える。
- 「黄色のセルの点数を変えると、すべての表が自動で変わる」ことを伝える。
- 欠席者を数えていないことを伝える。
