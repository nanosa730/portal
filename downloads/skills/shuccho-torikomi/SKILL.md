# 出張依頼の写真 → 入力シート取込行

Excel「出張整理」ブックに取り込むための行を作り、**Google ドライブの「出張取込」フォルダに保存する**。
Excel 側は「ダウンロードから取込」ボタンでフォルダの中身をまとめて読む。

**Googleカレンダーには登録しない。**（写真から予定を登録する普段の設定があっても、このスキルでは取込行を作って保存するだけにする）

## 出力形式（厳守）

コードブロックに、1件1行で次の形式を書く。区切りは半角の縦線 `|`。

```
取込|月|日|先生|区分|1日／時間|行き先と内容
```

- 先頭は必ず `取込`（マクロはこの行だけを読む）
- **月・日**：半角数字（例 `10|28`）。複数日の行事は日ごとに1行
- **先生**：下の職員名簿の表記どおり（姓と名の間は全角スペース）
- **区分**：`出張` `年休` `職免` `職免2-9` `職免2-9-2` のどれか
- **1日／時間**：出張は空欄。年休・職免は `1日` または `1時間`〜`7時間`
- **行き先と内容**：`内容　時刻　場所` を全角スペースで区切って短く書く
  - 内容：会の名前を短くする（例「第54回東海・北陸地区公立学校教頭会研究大会…」→「教頭会研究大会」）
  - 時刻：受付時刻があれば受付開始、なければ開始時刻。`9:30` のように半角
  - 場所：会場名を短く（例「Niterra日本特殊陶業市民会館 フォレストホール」→「日本特殊陶業市民会館」）
  - 例：`中学校部会　9:30　〇〇会館`、`授業公開　12:00　〇〇中`、`区校長会　9:00　区役所`
- `|` は内容の中に使わない

## Google ドライブへの保存（毎回必ず）

取込行ができたら、Google ドライブのツールで新しいテキストファイルを作る。

- 保存先フォルダ：「出張取込」
  - `title = '出張取込'` のフォルダを検索し、なければ作る（フォルダIDが分かっていれば、ここに書いておくと速い）
- ファイル名：`出張取込_YYYYMMDD_HHMM.txt`（作成した日時。同じ名前にならないよう分まで入れる）
- 中身：取込行だけ（説明文や ``` は入れない）。1件1行、UTF-8
- `contentMimeType` は `text/plain`、`disableConversionToGoogleType` は `true`（Googleドキュメントに変換させない）
- 先生が `？` など確定していない行は保存しない。確認してから保存する
- 既存ファイルの書き換えや削除はしない（Excel 側が同じ行を二度入れないようにしている）

保存したら「ドライブに保存しました（○件）」と一言添える。

## 読み取りの手順

1. **誰が行くか**を決める
   - 宛先・本文の「教頭先生の出席」「校長出席」「養護教諭」「○○担当者」などから役職を読む
   - 役職を職員名簿で氏名にする。マーカーや手書きで名前が書いてあればそちらを優先
   - 決められないときは推測で埋めず、先生欄を `？` にして質問する
2. **日付**：令和→西暦はしなくてよい（月・日だけ）。複数日なら日ごとに行を分け、日ごとの会場・時刻を使う
3. **会場が複数**（分科会ごとなど）のときは、マーカー・丸囲みされた方を使う。なければ両方を併記して確認する
4. 取込行のあとに、**確認してほしい点**（推測した部分）を箇条書きで短く書く

## 職員名簿（役職つき）

**使う前に、この表を自校の職員名簿に書き換える。** 表記は Excel ブックの「職員一覧」シートと完全に一致させる（姓と名の間は全角スペース）。名簿にない名前はマクロが受け付けない。

| 役職 | 氏名 |
|---|---|
| 校長 | 〇〇　〇〇 |
| 教頭 | 〇〇　〇〇 |
| 主幹教諭 | 〇〇　〇〇 |
| 養護教諭 | 〇〇　〇〇 |
| 校務主任 | 〇〇　〇〇 |

その他の職員：（ここに全職員の氏名を「、」区切りで書く）

※ 名簿が変わったら、ブックの「職員一覧」シートに合わせてこの表を直す。

## 出力例

```
取込|10|28|山田　太郎|出張||教頭会研究大会　12:30　日本特殊陶業市民会館
取込|10|29|山田　太郎|出張||教頭会研究大会分科会　8:30　ウインクあいち
```

確認してほしい点：
- 29日の会場はマーカーのある「ウインクあいち」（3〜5分科会）にしました

- すぐ入れたいとき：コードブロックをコピー → 「写真から取込」ボタン
