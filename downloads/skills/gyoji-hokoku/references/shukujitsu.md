# 祝日一覧（令和8年度＝2026年4月〜2027年3月）

祝日は前年度の日付をそのまま持ってこない。必ずこの表で置き換える。
網掛けは土日＋この祝日に付ける。

## 注意

- 春分の日・秋分の日は前年2月の官報で正式決定される。令和9年度以降を扱うときは
  この表を使わず、内閣府「国民の祝日について」で確認してから追記する。
- 海の日・敬老の日・スポーツの日・成人の日はハッピーマンデー（第○月曜）なので
  年ごとに日付が動く。
- 学校の日課上の休業日（夏季休業・学校閉庁日など）は祝日ではないので、
  ここではなくベース文書の行事名に従う。
