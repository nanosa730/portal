# 学校行事予定について（報告）の月次作成

前年度同月のdocxを**そのまま様式ごと流用**し、日・曜・行事名・網掛け・
ヘッダーだけを対象月に組み替える。様式は絶対に作り直さない。

## 前提

- ユーザー（学校で行事報告を担当する教員）が毎回ベースとなるdocxを添付する。
- 添付がないときは「前年度同月のWordを添付してください」と依頼して止まる。
- 文書番号は毎回ユーザーに聞く（推測して埋めない）。

## 手順

### 1. ベースを読む

```bash
python scripts/read_base.py <ベース.docx>
```

ヘッダー（文書番号・発信日・「○月分行事」）と、日／曜／行事名の一覧が出る。
**ベースの曜日は前年度のものなので、そのままでは使えない**ことを前提に読む。

### 2. 対象年月と文書番号を確認する

対象年月がはっきりしないときは聞く。文書番号（「○〇〇中第○○号」の号数）は
必ず聞く。発信日は既定で1日。異なるなら聞く。

### 3. 行事を対象月に割り付ける

原則は **曜日を保つ**（第1木曜の職員会議は対象月の第1木曜へ）。
ただし次のケースは**必ず質問してから決める**。勝手に決めない。

- **日付が意味を持つ行事**：始業式・終業式・入学式・卒業式・修了式など。
  曜日で寄せると学期の初日からずれるので、「日付優先か曜日優先か」を聞く。
- **割り付け先が重複するとき**：別々の日にあった行事が同じ日に来る場合。
  同日でよいか、片方をずらすかを聞く。
- **第5週の行事**：ベースに第5月曜があって対象月にないときなど。
  最後の同曜日に寄せてよいかを聞く。
- **複数日にまたがる行事**：中間テストの木・金など。連続を保つのが原則だが、
  祝日をまたぐ場合は聞く。

質問は選択肢を示して1〜3問にまとめる。複数の判断が絡むときは、
1回目の回答で新たな矛盾（重複など）が出ることがあるので、その時点で再度聞く。

### 4. 祝日を置き換える

`references/shukujitsu.md` を読み、ベースの祝日行は捨てて対象年度の日付で入れ直す。
祝日名（敬老の日・秋分の日など）は行事名欄に書く。

### 5. 組み立てる

日→行事名のJSONを作り、スクリプトを実行する。

```bash
python scripts/build_report.py \
  --input <ベース.docx> --output <出力.docx> \
  --year 2026 --month 10 --events events.json \
  --doc-number 61 --issue-day 1 \
  --shade 3,4,10,11,12,17,18,24,25,31
```

- `events.json` は `{"1": "始業式　防災訓練", "24": "中間テスト"}`。
  行事名の区切りは全角スペース、複数の会議は「・」でつなぐ（ベースの書き方に合わせる）。
- `--shade` は網掛けする日。**土日＋祝日**を明示的に列挙する。省略すると土日のみ。
- 月の日数（28/29/30/31）は自動で行を増減する。最終行の太い罫線は保たれる。
- ヘッダーの文書番号・発信日・「○月分行事」は全角数字で書き換わる。

### 6. 目視で確認してから渡す

```bash
python /mnt/skills/public/docx/scripts/office/validate.py <出力.docx>
python /mnt/skills/public/docx/scripts/office/soffice.py --headless --convert-to pdf <出力.docx>
pdftoppm -jpeg -r 100 <出力.pdf> page
```

生成した画像を必ず開いて、次を確認する。

- 1日の曜日が対象月と合っているか
- 網掛けが新しい土日・祝日の行に付いているか（旧暦の位置に残っていないか）
- ヘッダーの年・月・文書番号
- 末尾の日（30日か31日か）と最終行の太線

確認できたら `present_files` で渡し、割り付けた行事を表で示す。
文書番号や発信日など**ユーザーの確認が要る点は最後に短く挙げる**。

## やらないこと

- 様式・フォント・列幅・校長名の変更（指示がない限り触らない）
- 行事名の創作。ベースにない行事を足さない
- 網掛けを勝手に外す。この文書は教育委員会提出用で、配布プリントではない
