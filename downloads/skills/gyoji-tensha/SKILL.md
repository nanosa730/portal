# 行事予定 転記スキル（職員室掲示用）

## When to use
「R８9️⃣」「R８🔟」のような**月別の行事予定原稿シート**から、**職員室掲示用の月シート（例：`10月(R8)`）**を作るとき。
「○月を反映して」「○月の掲示表を作って」「行事予定を転記して」等の依頼で使用する。

---

## 前提となるシート構成

### 転記元（原稿シート、例 `R８🔟`）
- シート名に**絵文字と末尾スペース**が入ることがある。必ず `worksheets.load("items/name")` → `JSON.stringify(name)` で正確な名前を取得する。
- **1日 = 3行ブロック**。日付 d のブロックは `3d+4` 〜 `3d+6` 行、**日付番号は B列の `3d+5` 行**、曜日は C列同行。
  - ⚠ このオフセットは月によって変わる可能性がある。**B列で数値が入っている行を実測**し、`(番号行 - 5) / 3 = d` が成立するか検証してから進める。
- 列の役割：

| 列 | 内容 | 転記先 |
|---|---|---|
| B | 日 | （検証用） |
| C | 曜 | 3行目の照合用 |
| D | 生徒 | **8行目** |
| E | 週番 | 6行目（既定：転記しない。指示があれば） |
| F | その他 | **10行目（職員）** |
| G | ランチ | 転記しない |
| H | クラス順 | 転記しない |
| I〜O | 授業（時間割） | 転記しない |
| P | 時間帯 | **4行目「帯」**（☆/A/Ｂ） |
| Q | 1年 | **5行目「1年」**（X/Y） |
| R・S | 部活 | 転記しない |
| V〜Y | 古い下書き | **無視する** |

### 転記先（掲示シート）
- 前年度の同月シート（例 `10月`）を `worksheet.copy()` で複製 → `10月(R8)` にリネーム。書式・罫線・行高をそのまま継承する。
- 行構成：2=日付／3=曜日／4=帯／5=1年／6=週／8=生徒／10=職員。
- **列は day1 = C列**。列番号 = `2 + d`。31日月は AG、2月は AD/AE までになるので**月の日数に合わせる**（ハードコードしない）。
- **5行目・6行目は行の高さ0（非表示）のまま維持**する。勝手に表示しない。
- 8・10行目は **縦書き（textOrientation = 180）**。

Done when: 元シート名・ブロックオフセット・月の日数・転記先の最終列を確定できている。

## 手順

### 1. 新シート作成
`worksheet.copy(Excel.WorksheetPositionType.after, src)` → `○月(R8)` にリネーム。
内容クリア：`C4:AF6` / `C8:AF8` / `C10:AF10` / `AG1:AN13`（枠外の残りメモ）/ `B11:AF13`（範囲は月の最終列に合わせる）。
Done when: 4・5・6・8・10行目が空、行ラベル「帯／1年／週／生徒／職員」が残っている。

### 2. 日付・曜日
2行目に 1〜月末日、3行目に曜日。**元シートC列の曜日と全件一致するか照合**してから確定する（一致しなければ年度・月がずれているので停止して確認）。
Done when: 全日の曜日が元シートと一致。

### 3. 土日祝のグレー塗り
`C1:AF13` の塗りを一旦 `format.fill.clear()` → 土日祝の列だけ **各列の1〜13行**に `#D9D9D9`。
祝日は元シートD列に記載があるのでそれを正とする（例：敬老の日・国民の休日・秋分の日）。
Done when: 塗りが入っている列＝土日祝のみ。

### 4. 帯・1年
P列 `3d+5` → 4行目、Q列 `3d+5` → 5行目。元が空欄なら空欄のまま（補完しない）。
Done when: 読み戻して元シートと一致。

### 5. 生徒欄・職員欄の転記
各日 d について、`3d+4`〜`3d+6` の3行から値を取り、空を除いて `"\n"` で連結。
- D列 → `C8:AF8`
- F列 → `C10:AF10`

Done when: 読み戻して各日の内容が元シートのブロックと一致。

### 6. 時刻カッコの削除
全角・半角の括弧内が**時刻表記のみ**のものをカッコごと削除する。

```js
const re = /[（(]\s*[0-9０-９:：～~\-\s]*[:：][0-9０-９:：～~\-\s]*\s*[)）]/g;
let t = s.replace(re, "").split("\n").map(l => l.replace(/[\s　]+$/, "")).join("\n");
```

- 消す例：`(9:15～9:50)` `(10:１0)` `（14:00）` `(9:00～１０：００)` `(13:３0)` `(14:２0)`
- **残す例**：`（引き渡しなし）` `(3年)` `(雨天：月１)` `(現職後)` `（①全校予行練習 予備日）`
- カッコ外の時刻（例「13時・生徒下校完了」）は対象外。

Done when: 8・10行目に時刻だけのカッコが残っていない。

### 7. 縦書き用の行順反転
8行目・10行目の**改行を含むセル**のみ、行を `reverse()` して書き戻す。
理由：Excelの縦書きは**最終行が左端**に表示されるため、セル内を逆順で保持すると**左から読んで時系列**になる。
Done when: レンダリング画像で、各セルの左端が時系列で最も早い項目になっている。

### 8. 列幅の統一（必ず最後に）
**テキストの手直しが終わってから**実行する。
1. 各列の 8・10行目について**実際の表示列数**を数える（論理行数ではない。長い文言は縦書きで折り返して2列になる。例「いじめ問題行動等対策委員会」13文字は2列）。
2. 表示列数ごとに幅を統一する。実測値の目安（フォント14pt太字 ＭＳ Ｐゴシック）：

| 表示列数 | 幅(pt) |
|---|---|
| 空欄（土日祝） | 19.5 |
| 1 | 20.6 |
| 2 | 36.8 |
| 3 | 53.0 |
| 4 | 69.2 |
| 5 | 85.4 |

（1列あたり約16.2pt ＋ 余白約4.4pt）
- ⚠ `format.autofitColumns()` は余白が過大で**全体幅が広がる**ため使わない。表示列数の把握のためだけに一時利用するのは可。
- 適用後の合計幅を報告する。

Done when: 画像レンダリングで文字の切れ・隠れがなく、同じ表示列数の列が同一幅になっている。

### 9. 検証と報告
`getRange("B1:<最終列>10").getImage()` でレンダリングして目視確認。
報告に含める：シート名、行別の内容と出典、列幅グループ表、合計幅、**未反映の項目**（6行目「週」、ランチ・部活・時間割、元資料が空欄の箇所）。

## 判断に迷ったら聞くこと（1つずつ）
- 6行目「週」（E列 週番）を反映するか
- 元シートのV〜Y列に別内容がある場合の扱い
- 長い文言（「いじめ問題行動等対策委員会」等）を短縮するか
- 5行目「1年」を表示に戻すか

## やらないこと
- 行・列の非表示状態を勝手に変えない
- G・H・I〜O・R・S列を転記しない（掲示表に該当行がない）
- 数値・文言を推測で補完しない
