# 保護者配信メール作成

添付の案内文書から保護者向け一斉配信メールの文面を作る。

## 使う前に

このファイル内の `〇〇市立〇〇中学校`（差出人）と `【〇〇中】`（件名の頭）を、自校のものにすべて置き換えてから使う。

## 手順

1. 添付資料を読み、次の情報を拾う：宛先（学年など）、行事名、日時、会場、内容、持ち物・来校時の注意、回答期限、回答フォームURL、その他の連絡事項。
2. 下の型に当てはめて、件名と本文をチャットにそのまま書く（ファイルは作らない）。
3. 資料に書かれていない情報は補わない。読み取れない・あいまいな箇所があれば、文面の後に一言だけ確認する。

## 文面の型

```
**件名：** 【〇〇中】【宛先】行事名のご案内

**本文：**

宛先の皆様

日頃より本校の教育活動にご理解とご協力をいただき、ありがとうございます。
（行事名）を下記のとおり行います。詳細は添付資料をご確認ください。

■日時：
■会場：
■内容：
※補足（生徒参加など）

【ご来校にあたってのお願い】
・（持ち物・名札・入口・駐車駐輪などを箇条書き）

【出欠のご回答】（回答が必要な場合のみ）
（期限）までに、下記フォームよりご回答をお願いいたします。
（URL）

〇〇市立〇〇中学校
```

## 書き方のルール

- 件名の先頭には必ず【〇〇中】を付ける（例：【〇〇中】【1年生保護者】保護者会のご案内）。
- 時候の挨拶は省き、あいさつは1文にする（メールはスマホで読まれるため短く）。
- 日時は「10月23日（金）13:10～14:30」のように半角数字で書く。
- 会場は「本校 体育館」のように、自校なら「本校」と略す。
- 注意事項は資料の順を保ち、1項目1行に簡潔にまとめる。
- 回答期限とURLは必ず本文に入れる（QRコードはメールでは読めないため）。URLは資料に記載のものを正確に写す。
- 「詳細は添付資料をご確認ください」を入れる（資料を添付して配信する前提）。
- 差出人は「〇〇市立〇〇中学校」のみ。校長名は入れない。
- 回答不要・注意事項なしなど、該当しない見出しは丸ごと省く。
