# メール返信作成

受け取ったメールへの返信文を作成する。

## 使う前に：署名の設定

**下の署名を自分のものに書き換えてから使う。**

```
〇〇市立〇〇中学校
（職名）　〇〇〇〇
〒000-0000 （住所）
TEL 000-000-0000　FAX 000-000-0000
E-mail （メールアドレス）
```

## トリガー

- 「メールの返信をして」
- 「このメールに返信して」
- その他、メールへの返信文作成の依頼全般

## 前提となる入力

ユーザーは通常、以下をまとめて（または続けて）提示する:
1. 元のメール本文（貼り付け）
2. 返信に書いてほしい内容の箇条書き

どちらか一方しかない場合は、まず不足分を聞く。

## ワークフロー

1. 元のメール本文と箇条書きの内容を読み、返信作成に**必要な情報**を洗い出す。以下を目安に、一度に一つずつ、簡潔に質問する（すでにメール本文や箇条書きから読み取れる項目は聞かない）:
   - 宛先の相手の呼び方（会社名・氏名・敬称。メール署名や本文から分かればそれを使い、確認のみでよい）
   - 返信のトーン（フォーマル度：かなり丁寧／通常のビジネス敬語／ややカジュアル）
   - 箇条書きの各項目について、返信文にどう反映すべきか曖昧な点（日程・金額・可否など具体的な事実関係）
   - 返信の締め・結びに含めたい定型句の有無（次回のアクション、お詫び、御礼など）
2. 全ての必要事項が揃ったら、返信文の全文をテキストで提示する。
   - 書き出し：宛名（例：「〇〇様」）
   - 本文：季節・冒頭挨拶は元メールのトーンに合わせて簡潔に。箇条書きの内容を過不足なく、自然な文章として組み込む
   - 結び：簡潔な結びの挨拶
   - 署名：冒頭「署名の設定」の署名をそのまま使う
3. 提示した返信文についてユーザーに確認を取り、修正依頼があれば反映する。

## 出力形式

チャット内にテキストで返信文を提示する（Wordファイル化は不要。ユーザーから明示的にWordファイルでの出力を求められた場合のみ`.docx`で作成する）。
