# 保護者への案内文（記書き形式）

保護者宛のお知らせ文書を、格式のある「記書き」形式でWord（.docx）ファイルとして作成する。

## 使う前に：差出人情報の設定

**この2行を、使う学校のものに書き換えてから使う。**

- 差出人（役職）：`〇〇市立〇〇中学校長`
- 差出人（氏名）：`〇〇　〇〇`（姓と名の間に全角スペース。文書内では「〇　〇　〇　〇」のように1字ずつ空ける）

`scripts/create_annai.js` の冒頭にも同じ2つの定数（`senderOrg` / `senderName`）があるので、あわせて書き換える。

## トリガー

以下のような依頼があったら、このスキルに従って文書を作成する:
- 「保護者への案内文を作成して」
- 「保護者向けのお知らせを作って」
- 「保護者会の案内文を作って」
- その他、保護者宛の正式な案内・お知らせ文書の作成依頼全般

## ワークフロー

1. 案内文の内容（行事名、日時、場所、参加方法、締切など）についてユーザーに必要事項を確認する。一度に一つずつ質問し、簡潔に進める。
2. 内容が整ったら、下記の「文書フォーマット」に従って本文を組み立て、ユーザーに一度テキストで提示して確認を取る。
3. 確認が取れたら、`scripts/create_annai.js` を使ってWord（.docx）ファイルを生成する。
4. 生成後はPDFに変換して画像化するなどして、レイアウト崩れがないか目視で確認してからユーザーに渡す。

## 文書フォーマット（固定の型）

段落構成は以下の順番・配置を厳守する:

1. **右揃え**：発行日（例：「令和8年7月13日」。和暦・元号は依頼日から判断し、不明なら確認する）
2. **左揃え**：「保護者　様」
3. **右揃え**：差出人（役職）
4. **右揃え**：差出人（氏名）。文字間に全角スペースを入れる
5. **中央揃え**：文書タイトル（太字・やや大きめのフォント。「〇〇について」のように簡潔に。「（お知らせ）」は付けない）
6. **左揃え**：時候の挨拶（「いつも本校の教育活動にご理解・ご協力をいただき、誠にありがとうございます。」）
7. **左揃え**：本文（背景・趣旨説明。文末は「～行ってきたところです。」「～実施いたします。」のように丁寧・簡潔にまとめる）
8. **中央揃え**：「記」
9. **左揃え**：項目を全角数字「１　２　３…」＋全角スペース＋項目見出し（太字）で列挙し、次の行に字下げした説明文を続ける。**「、」は付けない**（「一、」ではなく「１　」）
   - 二次元コードを併記する項目では、URLと画像を段落内に挿入する（`scripts/create_annai.js` の `imagePath` を参照）

「以上」・問い合わせ先（連絡先）は付けない。項目の列挙で文書を終える。

## Word生成

`scripts/create_annai.js` を参照。Node.jsの `docx` パッケージを使用する。実行例:

```bash
npm install docx
node scripts/create_annai.js
```

スクリプト冒頭の `senderOrg`・`senderName`（初回のみ）と、`issueDate`・`title`・`intro`・`body`・`items`・`outputPath`（案件ごと）を書き換えて使う。項目は `{label: "参加方法", text: "..."}` のような配列で渡し、自動で「１　２　３…」が付く。「以上」・連絡先は出力しない。
